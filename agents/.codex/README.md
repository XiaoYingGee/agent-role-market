# Codex Adapter

This adapter provides a generic Codex-style setup.

Suggested use:

```text
Copy agents/.codex/AGENTS.md into a project root or merge it into an existing AGENTS.md.
Copy agents/.codex/skills/agent-role-market/SKILL.md into your Codex skills directory if your setup supports skills.
```

The adapter is intentionally tool-light. It tells Codex how to select role packs and workflows from this repository without assuming private paths or project-specific state.
