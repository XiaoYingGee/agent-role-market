# Agent Role Market Skill

Use this skill when a task benefits from explicit role selection, workflow selection, handoff requirements, or review gates.

## Process

1. Identify the work type.
2. Choose one primary role from `roles/`.
3. Add at most two supporting roles.
4. If applicable, choose a workflow from `workflows/`.
5. State the selected role and workflow before execution.
6. Complete the task with text-based evidence and a handoff summary.

## Completion Standard

Do not mark work complete unless there is a conclusion, artifact location, verification evidence, and remaining-risk statement.
