## Device and environment information

This repository is **device-agnostic**. It contains no device paths, credentials, SSH aliases, or environment-specific configuration.

For device-specific setup (OS, installed tools, directory conventions, service management), refer to your personal knowledge repository. If you use [knowledge-for-everything](https://github.com/XiaoYingGee/knowledge-for-everything), see `devices/` and `setup/` there.
